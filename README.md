# CS-230-The-Gaming-Room

This repository contains the complete software design document created for The Gaming Room, a client developing the multiplayer game Draw It or Lose It. The goal of this project was to design a scalable, secure, and cross-platform architecture to support the game’s expansion beyond Android and into web-based and desktop environments.

The document provides detailed recommendations for server platforms, operating system architectures, memory and storage management, distributed systems, and network security. It demonstrates my ability to analyze client needs, evaluate technical solutions, and clearly communicate design concepts to both technical and non-technical audiences.

**Skills Demonstrated:** System Architecture Design • Linux Administration • UML Modeling • Cloud Storage • Distributed Systems • Security • Technical Writing

## **Reflection Journal**

Working on this project for The Gaming Room strengthened my understanding of how theoretical concepts connect with practical system design. The client needed a reliable and scalable system capable of supporting high user activity across multiple platforms. Their main goals included stability, performance, and data security. My task was to design a system architecture that would meet these needs while staying efficient and cost-effective.

This project taught me the importance of thoughtful design before beginning any development work. By breaking the system into layers such as server, client, storage, and network, I was able to identify how each component affects performance and user experience. Documenting these choices helped clarify how design decisions support both the client’s goals and the technical feasibility of implementation.

I am proud of how professional and detailed the final software design document turned out. I focused on maintaining clear communication that would make sense to both developers and business stakeholders. I also enjoyed researching the strengths of different operating systems and distributed system models, which allowed me to make confident, evidence-based recommendations for the client.

If I were to revise this project, I would add more detail about continuous integration and deployment workflows as well as secure authentication methods. These additions would make the document even more aligned with real-world development practices and provide a more complete picture of how updates and testing could be managed.

Interpreting user needs was central to this project. Because Draw It or Lose It is a fast-paced, multiplayer game, it was critical to prioritize responsiveness, reliability, and user data protection. My design recommendations focused on these areas by suggesting a Linux-based platform, RESTful API communication, and scalable cloud storage. Keeping the user experience in focus helped ensure that the technical design would also feel seamless and accessible to players.

Overall, this project improved my ability to think like a systems analyst and approach design with both structure and creativity. Moving forward, I plan to use similar techniques such as structured documentation, UML modeling, and containerization to plan complex software systems. This experience reinforced that a strong design foundation is essential for building efficient, adaptable, and lasting software.
